# 🤖 AI-Generated Image Detection Using Machine Learning

![lv_0_20261016210625.jpg](https://github.com/user-attachments/assets/df2bc96f-a0f6-49b1-bb30-be9fc3806998)

I developed a Machine Learning project to distinguish between real human faces and AI-generated faces.

## 🔹 Key Features:

- Trained a Machine Learning model for image classification.
- Used a dataset of 9,630 face images, including 5,000 real face images and 4,630 AI-generated face images.
- Developed an interactive web application for image uploads and predictions.

## 🛠️ Technologies: Python, Scikit-learn, Joblib, and Streamlit.

🚀 Dataset :- https://www.kaggle.com/datasets/kaustubhdhote/human-faces-dataset
